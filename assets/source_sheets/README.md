# assets/source_sheets/

Hojas de arte propio del proyecto (composiciones generadas por IA por Marcos,
fuera del repo). **Sin recortar y sin cablear a escenas.** Son el material
fuente para las fases de implementacion: cada seccion del juego que lo
necesite extrae de aca lo que corresponda (pipeline PIL: componentes
conexos por alfa + re-ancla de pie, igual que `player/vaelith_custom`).

`.gdignore` evita que Godot importe estas composiciones grandes.

Ya implementado (extraido) vive en `assets/sprites/` y NO se toca todavia.
